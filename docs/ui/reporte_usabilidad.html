El prototipo interactivo permite navegar de forma fluida por el ciclo completo de interacción del usuario en el ERP de RRHH. Incluye transiciones entre pantallas, modales de confirmación, estados de carga y validación de formularios.

2. Enfoque Mobile-First y Responsive Web

La interfaz fue diseñada con una estrategia Mobile-First & Adaptive Grid, garantizando una usabilidad consistente en resoluciones desde móviles (375px) hasta monitores UltraWide (1440px+).

  • Móvil (375px - 767px): Menú hamburguesa colapsable, formularios en columna única y tablas adaptadas a tarjetas flexibles.
  • Tablet (768px - 1023px): Sidebar compacto de iconos y cuadrícula a 2 columnas para formularios.
  • Escritorio (1024px+): Panel lateral de navegación persistente, tablas completas con paginación y modales centrados.

3. Mapa de Navegación del Sistema (User Flow)

La estructura de flujo entre pantallas sigue una arquitectura jerárquica clara:

[Pantalla de Autenticación /login] │ ▼ [Panel Principal /dashboard] ├──► [Listado Colaboradores /dashboard/empleados] ──► [Formulario /nuevo] ├──► [Procesamiento Nómina /dashboard/nomina] ──► [Detalle /id] └──► [Solicitudes Ausencia /dashboard/solicitudes] ──► [Crear Solicitud]
